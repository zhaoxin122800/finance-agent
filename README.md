# Finance Agent

面向个人 A 股研究的本地 Web 金融助手，基于 Python、FastAPI 和兼容 OpenAI 接口的大语言模型构建。将自选股监控、行情图表、多维 AI 解读、模拟交易、每日复盘、政策跟踪、研报提炼和策略回测整合到浏览器工作台。

项目将行情采集、知识检索、模型分析与结果归档连接起来，方便查看原始数据后继续分析、模拟操作和复盘。账户与分析记录保存在本地，模型服务地址和模型名称通过环境变量配置。

## 实现细节

### 四维并行 AI 分析

个股分析首先汇集行情、K 线、资金流、龙虎榜、公告与公司画像，再按任务提取输入，分别调用模型生成四个维度的解读。

| 分析维度 | 主要输入 |
| --- | --- |
| 量价技术面 | K 线、实时报价与分时量能 |
| 资金面与游资 | 资金流、龙虎榜与行情字段 |
| 基本面与估值 | 实时行情中的估值等字段 |
| 公司画像与产业链定位 | 公司业务画像 |

四个任务通过 ThreadPoolExecutor 并行执行，随后按固定顺序合并。模型调用失败时，相关维度输出提示，其他维度继续生成结果。分析按股票代码和日期归档，同日重复请求优先读取已保存的内容。

### 本地知识检索

从 vendors/quant_kb 中读取 Markdown 知识资料，按标题和空行分段，通过关键词子串匹配召回相关内容。检索结果去重后最多返回 8 个片段，每个片段截取前 600 个字符，再注入模型的系统提示词。知识文件可直接维护，适合术语相对集中的个人研究场景。

### 数据回退与异常处理

FreeSource 在数据适配层统一字段结构。实时行情按腾讯到新浪回退，K 线按百度到新浪回退，没有可用数据时返回空结果。实时行情使用进程内 TTL 缓存，默认有效期为 30 秒，减少重复请求。

公司公告与公司画像在装配时独立捕获异常，失败时保留其他已经取得的数据。页面据实际返回内容展示，免费数据接口的时效与完整度受上游服务影响。

### 本地状态管理

账户、自选股等状态以 JSON 文件保存在 data 目录，分析报告以 Markdown 归档。JSON 写入先生成临时文件，再替换目标文件。读取失败时尝试备份损坏文件并返回默认值，启动时校验模拟账户的必要字段，缺失或无效时初始化账户。

### 请求处理流程

浏览器请求进入 FastAPI 路由后，由 services 层装配业务数据，datasources 层获取外部行情，ai 层完成知识检索与模型调用。业务结果写入本地状态或报告归档，再通过 Jinja2 页面和 JavaScript 图表展示。

## 技术分层

| 层次 | 框架或工具 | 用途 |
| --- | --- | --- |
| Web 服务 | Python 3.10+、FastAPI、Uvicorn | 路由、表单处理与本地 HTTP 服务 |
| 页面与图表 | Jinja2、JavaScript、Lightweight Charts | 页面渲染、交互和行情图表 |
| 模型调用 | OpenAI Python SDK | 调用可配置的兼容接口 |
| 数据请求 | HTTPX、urllib、复用的数据脚本 | 获取行情、公告和资料 |
| 并发处理 | ThreadPoolExecutor | 并行执行四维分析 |
| 知识检索 | Markdown、关键词匹配 | 召回金融知识上下文 |
| 状态存储 | JSON、Markdown、pathlib | 保存账户、自选股及报告 |
| 开发验证 | uv、pytest、pytest-asyncio | 依赖管理与自动化测试 |

## 配置说明

| 变量 | 默认值 | 作用 |
| --- | --- | --- |
| LLM_BASE_URL | https://open.bigmodel.cn/api/paas/v4 | 模型接口基础地址 |
| LLM_API_KEY | 空 | 配置有效密钥后启用 AI |
| LLM_MODEL | glm-4-flash | 模型名称 |
| DATA_SOURCE | free | 默认免费数据适配，paid 为预留配置 |
| CACHE_TTL_REALTIME | 30 | 实时行情缓存秒数 |
| HOST | 127.0.0.1 | 服务监听地址 |
| PORT | 8000 | 服务端口 |

Windows PowerShell 可用 Copy-Item .env.example .env 复制配置。更换模型服务时，应同步核对接口地址、模型名称及兼容性。

PDF 文本提取可通过 uv sync --extra pdf 安装可选依赖。增强行情查询通过 uv sync --extra data-premium 安装，两组依赖可同时指定。PDF 解析效果取决于文件的文本层内容。

## 使用流程

1. 启动服务并在浏览器访问本机 8000 端口，添加关注股票。
2. 打开个股分析，查看行情、K 线、资金与公司资料。
3. 配置模型密钥后生成四维解读，结合原始数据核对内容。
4. 在模拟账户记录操作，再通过每日复盘查看账户变化。
5. 按研究需要使用政策、研报、风险扫描和策略回测模块。

默认模拟账户初始资金为 10 万元。回测提供均线交叉、放量突破等内置策略，输出收益、最大回撤、夏普与胜率。结果依赖历史数据及简化成交假设。

## 本地数据与模型请求

.env 与 data 目录已加入 Git 忽略规则。启用 AI 后，相关行情、持仓摘要或输入资料可能发送至配置的模型服务。项目采用本地文件存储，默认监听本机地址，适用于个人本地研究。

## 快速开始

```bash
# 环境要求 Python 3.10+，并预先安装 uv
# 1. 安装依赖
uv sync

# 2. 配置 LLM（可选，不配也能用非 AI 功能）
cp .env.example .env
# 编辑 .env 填入 LLM_API_KEY

# 3. 启动
uv run python -m app.main

# 4. 打开浏览器
# http://127.0.0.1:8000
```

## 数据源

实时行情与 K线采用**降级链**(主源失败自动切备源):

| 接口 | 主源 | 备源 | 说明 |
|------|------|------|------|
| 实时行情 | 腾讯财经(零依赖) | 新浪 | 腾讯提供 PE/PB/市值/涨跌停等富字段 |
| K线 | 百度股市通(带MA) | 新浪 | 百度返回自带 MA5/MA10/MA20 |
| 分时/板块/资金流/龙虎榜 | 新浪 | — | M2-M4 按需升级 |

另有 27 个增强端点(东财研报/融资融券/解禁/同花顺热点/北向资金/iwencai 语义搜索等)封装在 `vendors/a_stock_data.py`,需可选依赖:

```bash
# 解锁全部 27 端点(东财/同花顺/mootdx 五档盘口等)
uv sync --extra data-premium
```

未安装可选依赖时,相关端点抛友好 ImportError,核心行情(腾讯/新浪/百度)零依赖可用。
